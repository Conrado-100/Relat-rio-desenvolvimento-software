# 📚 Curso de Desenvolvimento de Software

Curso interativo sobre **Desenvolvimento de Software**, organizado em cinco módulos progressivos, desde os fundamentos de Engenharia de Software até temas relacionados à validação, testes, segurança, manutenção e evolução de sistemas.

O projeto foi desenvolvido como uma aplicação web estática utilizando HTML, CSS e JavaScript, podendo ser executado localmente ou publicado através do GitHub Pages.

---

## 🎯 Objetivo

O objetivo deste projeto é organizar os principais conceitos estudados durante o desenvolvimento de software em uma sequência de aprendizagem progressiva.

A proposta é começar pelos conceitos fundamentais e avançar gradualmente para assuntos mais complexos, utilizando:

- 📖 Explicações teóricas
- 💡 Exemplos práticos
- 📊 Diagramas
- ✅ Checklists
- 🧠 Quizzes
- 📈 Sistema de acompanhamento de progresso
- 🔄 Conteúdo organizado de forma incremental

---
